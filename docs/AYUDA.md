# Si algo falla

**El doble clic no abre Plaza.** Comprueba que extrajiste el ZIP completo. Abre una terminal dentro de la carpeta donde ves `iniciar.py`. En Windows ejecuta `py -3 iniciar.py` (o `python iniciar.py`). En macOS y Linux ejecuta `python3 iniciar.py`. Si falta Python, vuelve al segundo paso del README.

**El navegador no se abre o el icono instalado pide el lanzador.** Deja el lanzador abierto y visita http://127.0.0.1:8826/. Si el puerto está ocupado, comprueba si ya tienes otra ventana de Plaza abierta.

**No veo la opción de instalar.** Puedes estudiar en una pestaña normal. Para tener un icono, abre la dirección local en Chrome o Edge y busca la opción de instalación en su menú.

**El tutor no encuentra modelos.** Ejecuta `ollama list`, comprueba que Ollama está abierto y vuelve a abrir el tutor. El navegador y Ollama deben estar en el mismo ordenador. Si al generar falta memoria, cierra otras aplicaciones o descarga un modelo más pequeño. [Configurar el tutor](TUTOR.md)

**Quiero conservar mi progreso al actualizar la aplicación.** Cierra el lanzador, descarga y extrae el nuevo ZIP y abre la nueva copia con el mismo navegador y dirección. Si clonaste el repositorio, puedes ejecutar `git pull --ff-only` y volver a iniciar. Borrar los datos del sitio, utilizar navegación privada o cambiar de perfil afecta al historial local.

**La fecha del catálogo parece antigua.** Mira la fecha de revisión en Oposiciones. Conéctate a internet, abre Plaza, espera a que termine la descarga y vuelve a cargar. Consulta el BOE y las bases antes de presentar una solicitud.

**Uso Gmail en el navegador y no se abre el borrador.** Envía tu comentario a learntouseai@gmail.com desde Gmail. Incluye la pregunta o el anuncio y qué esperabas ver.

**Quiero buscar datos nuevos ahora.** Pulsa **Actualizar datos** en el menú (↻ en móvil) y elige **Buscar actualizaciones**. Si hay novedades, termina el test o simulacro actual antes de volver a abrir Plaza. La descarga conserva los bancos anteriores si falla y mantiene las preguntas, el historial y los repasos si se aplica. Usa el mismo navegador y dirección para conservar el progreso.
