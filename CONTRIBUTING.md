# Colaborar con Plaza

1. Busca si ya existe una incidencia parecida. Para comunicar un fallo, indica qué hiciste, qué esperabas y qué ocurrió. Si afecta a un ejercicio, añade su identificador, la convocatoria y el enlace al precepto aplicable.
2. Crea una copia del repositorio en GitHub con **Fork**, clónala y trabaja en una rama propia.
3. Prueba el cambio en local con `python3 iniciar.py`. Si tocas los datos, regenera el manifiesto con `python3 mantenimiento/manifiesto.py` y ejecuta `python3 mantenimiento/comprobar.py`.
4. Abre una solicitud de cambios hacia `main`. Resume el cambio, enlaza la incidencia y describe las comprobaciones. Para material de estudio, indica la fuente oficial y su fecha o redacción.

Puedes proponer próximas oposiciones estatales indicando el cuerpo, el turno y el enlace a las bases. Conserva los identificadores de las preguntas existentes para que sus resultados y repasos sigan disponibles. Si detectas una pregunta obsoleta, indica la redacción afectada para que pueda marcarse como retirada de los tests nuevos.
